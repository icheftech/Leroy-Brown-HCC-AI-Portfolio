# Portfolio Presentation Narrative Plan

## Audience

Instructor, classmates, recruiters, and technical reviewers evaluating an Applied AI and Robotics portfolio.

## Objective

Present Leroy Brown as a practical AI builder who can connect NLP, agentic systems, governance controls, and deployed applications into professional software projects.

## Narrative Arc

Start with identity and portfolio link, show the learning journey across NLP and AI systems, highlight the strongest projects, summarize the technical toolkit, and close with next steps.

## Slide List

1. Professional Introduction: name, program, specialization, GitHub portfolio link.
2. Learning Journey: timeline from NLP foundations to governed AI systems and deployed applications.
3. Project Showcase: NewsBot, SSO Control Plane, and bidops as flagship examples.
4. Technical Arsenal: AI/NLP, agent workflows, backend, frontend, governance, deployment.
5. Reflection and Next Steps: production AI, responsible automation, and professional contact points.

## Source Plan

Use the public GitHub portfolio and project repositories as source anchors. Use local project READMEs where available for project descriptions.

## Visual System

Professional dark-on-light technical style with deep navy, cyan, green, and gold accents. Use editable cards, timelines, and skill bands rather than screenshot-only slides.

## Editability Plan

All slide titles, descriptions, metrics, URLs, skill labels, and project names should remain editable PowerPoint text.
